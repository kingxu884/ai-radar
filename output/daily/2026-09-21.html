GVPO++：Group Variance Policy Optimization 替代 GRPO，消除重要性采样训练不稳定性
发生了什么：论文提出 GVPO，将 KL 约束奖励最大化的解析解整合进梯度加权方案，梯度对应隐式奖励中心距离与实际奖励的均方误差，无需依赖 GRPO 的重要性采样。
为什么重要：Post-training 的稳定性一直是推理模型训练中的隐性瓶颈，GRPO 虽然驱动了 DeepSeek-R1 等模型，但其重要性采样的方差问题限制了更大规模部署。GVPO 提供了一个可解释、更稳定的替代方案，对国内厂商的 RL 管线有直接工程参考价值。
关联动态：与 TecCrunch 讨论的"AI 行业是否真的准备好减速"形成了有趣对照——训练基础设施的改进恰恰在降低继续加速的技术风险。
RBS-Attention：Radius-Bounded Sparse Prefill 解决长上下文推理中的"均值稀释"问题
发生了什么：论文指出稀疏块选择中块质心可能掩盖高相关 token 的"mean dilution"问题，提出训练无关的双分支稀疏 prefill 方法（质心基础分支 + 最大 key-block 半径救援分支）。
为什么重要：长上下文推理的成本瓶颈正从模型训练转移到推理侧 prefill，这直接影响 Agent 在长会话中累积上下文后的响应延迟与质量。对于使用 Claude Code 或 Cursor 处理大型代码库的开发者，这类优化意味着 Agent 的"记忆窗口"可以更高效地利用。
关联动态：同批论文中还有 ETA（Elastic Threshold Attention）和 TierKV（移动端分级 KV 缓存），共同指向一个趋势：上下文管理正在成为独立于模型架构的工程学科。
SpecOpt：从"生成新分子"转向"优化既有药物的结合特异性"
发生了什么：论文提出 specificity optimization 任务，对已有化合物进行约束性结构修改，增加其对目标蛋白的偏好并减少脱靶效应，同时保持结构身份和类药性。
为什么重要：这是 AI 药物发现从 de novo 生成走向临床导向优化的信号。现实中可成药的起点往往不是从零生成，而是对已知药物骨架的精细化改造。如果 Agentic 分子优化能嵌入真实的药物化学约束（合成可行性、专利空间），将比生成式模型更接近产业落地。
关联动态：与 EnSol（环境感知溶解度预测）和 MIRCID（miRNA 推断驱动药物机制建模）共同构成了今天 AI for Science 主题的"从生成到优化"转向。
CoVer：自对弈共训练 Coder 与 Verifier，解决代码生成 RL 中"许可性坍塌"与"集中偏差"
发生了什么：论文提出单一策略 GRPO 框架，用信息增益奖励对自生成测试打分，通过互信息与 ground-truth 锚定的正确性信号之间的关系来筛选测试质量和代码质量。
为什么重要：代码生成 RL 如果只用 pass-rate 奖励，模型会学会生成琐碎测试来游戏评估。CoVer 的信息增益门控机制实质上是在让模型"学会设计有区分度的测试"。这与 Harness 工程中"验证器设计"的核心命题高度一致——Agent 的可靠性最终取决于验证信号的不可欺骗性。
关联动态：与 LogicTrack（用形式化逻辑求解器审计推理轨迹）和 LEGIT（Agent 市场凭证协议）共同指向 Agent 生态的信任基础设施需求。
