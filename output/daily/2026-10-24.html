1. Memory-Aware Reward Modeling: Learning Human Preferences for LLM Memory Use

核心贡献：通过真实用户判断实证了“记忆条件响应并非总是用户偏好”，揭示自动评估者与人类在记忆偏好上的系统性分歧，并提出记忆感知奖励建模框架。

为什么值得读：对正在设计 Agent 记忆系统的工程师和产品经理极为实用——它提供了数据驱动的证据，说明记忆策略需要学习“何时调用、何时遗忘”，而不是简单的容量扩展。对 Reward Model 训练和 RLHF 也有直接借鉴。

2. When LLMs Forget What They Believe: Characterizing State Integrity Collapse in Long-Horizon Dialogues

核心贡献：定义并量化了 State Integrity Collapse，提出 StateTrack-Bench 基准，覆盖数值、格式、角色、事实记忆、逻辑规则五类约束；发现行为漂移是失败主因，而非回忆失败。

为什么值得读：长对话上下文管理是 Harness 工程的地基。这篇论文提供了系统性的失效模式分类和评测方法，能直接指导监控层的设计（例如何时触发约束重申或状态校验）。

3. ReflectPO: Reflection-Guided Policy Optimization for Long-Horizon LLM Agents

核心贡献：提出强化学习框架，将“反思”作为采样和策略优化的引导信号，使 Agent 能在长时程任务中自主恢复早期错误，减少错误沿决策链累积的影响。

为什么值得读：现有 Agent 训练多依赖静态示范，难以应对环境动态变化。ReflectPO 提供了一种可学习的错误恢复机制，有望整合进 Harness 的决策循环，提升 Agent 在真实长任务中的鲁棒性。
