Simon Willison 深度分析 ChatGPT 账户劫持漏洞链
发生了什么：Parameter Labs 发现 ChatGPT 的 HTML 预览沙箱存在复杂攻击链——通过 MathLive 虚拟键盘的 postMessage 接口触发父页面 innerHTML 注入，最终可访问 OpenAI API 和私有数据。
为什么重要：这是 Agent 工具调用架构的教科书级安全案例。sandboxed iframe 与父页面之间的 postMessage 边界是当前所有 Agent 产品（Claude Artifacts、ChatGPT Canvas、Cursor Preview）的共性薄弱点。任何引入第三方 JS 库的工具链都可能成为跳板。
关联动态：对正在自建 Harness 的 DeepSeek、智谱等国内厂商，以及所有使用 MCP 工具调用的开发者，这是必须立即审计的攻击面。

📖 今日推荐深度阅读
推荐：Ethan Mollick《Agency and Agents》（2026-08-31，One Useful Thing）
链接：https://www.oneusefulthing.org/p/agency-and-agents
为什么今天推荐：在 Agent 功能被过度炒作的当下，Mollick 从 Hugging Face 事件和"暮光工厂"（Twilight Factories）现象切入，提出了一个关键区分：真正的"Agency"（代理权/自主性）与"Agents"（执行器）之间的鸿沟。这篇文章正好呼应今天多个信号——Harness 的工程化、Agent 安全性、以及投资界对"务实 AI"的转向。
三个核心观点：
• Agency 的本质是"授权与责任"，而非"工具调用能力"——大多数所谓 Agent 只是自动化脚本的增强版。
• "暮光工厂"现象揭示了一个被忽视的现实：大量 Agent 在无人监督的状态下运行，产出质量参差不齐，却消耗真实资源。
• 真正的产品机会不在于堆叠更多工具，而在于设计清晰的 Agency 边界——什么交给 AI，什么必须有人类确认。
适合谁读：Agent 产品经理、正在设计 Multi-Agent 系统的架构师、对 AI 产品"虚假自动化"问题有疑虑的决策者。
预计阅读时间：12-15 分钟。
