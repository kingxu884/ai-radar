Simon Willison: smolvm as a sandbox for untrusted Python & JavaScript
为什么今天推荐：在 Agent 工具调用与 AI 生成代码执行的安全性日益重要的当下，沙箱技术是 Harness 工程的最后一道物理边界。这篇文章记录了用 Claude Code for web 调研 smolmachines 沙箱的真实过程，包括其限制（Web 版容器无法运行 smol machines）和方案探索，极具实际操作价值。
核心观点：
- 现代 Web 沙箱原语（如 WebAssembly、文件系统限制）能大幅降低扩展部署成本，提供良好安全边界，使 LLM 填充缺失功能成为可能。
- 可扩展软件的新机会：App 作为坚实核心，允许用户通过 LLM 安全地朝多方向扩展。
- 沙箱需确保对无限循环、网络访问、文件系统范围做出严格限制，才能将 AI 生成的不可信代码用于真实数据转换。
适合谁读：AI DevOps / Agent 平台工程师、工具链安全负责人、任何需要在生产环境执行 LLM 生成代码的开发者。
