🔬 值得深挖的论文/报告
1. 《Long-Horizon State Tracking in LLMs: Executing MD5 through a Deep Sequence of Dependent Tool Calls》 (arXiv:2609.00012)
核心贡献：通过让模型执行 MD5 哈希计算，干净地测试了 LLM 在长序列工具调用中维持精确中间状态的能力。发现即使每步准确率看似优秀，错误会随步骤数指数级累积，端到端失败概率急剧上升。
为什么值得读：直击 Agent 系统的核心弱点——状态跟踪。当前 Agent 基准混淆了指令理解和状态跟踪，这篇论文用密码学任务提供了无可争议的“纯状态跟踪”测试。对于正在设计 Harness 系统的工程师，理解这种级联失败模式是设计可靠 Agent 系统的前提。
2. 《Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems》 (arXiv:2609.00237)
核心贡献：解决多 Agent 系统中的“执行历史过载”问题——当多个 Agent 协作时，完整历史记录会膨胀成本。提出门控记忆路由，根据协作状态动态选择需要保留的上下文，而非保留全部历史。
为什么值得读：这是 Multi-Agent 系统的工程落地关键。当前多 Agent 系统要么牺牲上下文（丢失信息），要么保留全部历史（成本爆炸）。这篇论文提供了第三条路，对于正在构建生产级 Multi-Agent 系统的团队，这是可直接借鉴的架构方案。
3. 《Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents》 (arXiv:2609.00065)
核心贡献：构建了包含 163 种科学领域程序化知识的开源库，覆盖基因组学、化学信息学、医学影像、研究设计等 16 个领域。Agent 按需加载技能文件，每个技能包含版本化指令和可执行脚本。
为什么值得读：这是 AI for Science 的“技能基础设施”蓝图。它解决了科学 Agent 的核心困境——模型知道“是什么”但不知道“怎么做”。将领域最佳实践（如“这个领域用哪个统计检验”、“结果需要附带哪些限制条件”）编码为可调用的技能，是让 AI 科学家从“能写代码”到“能做可靠科研”的关键一步。
📖 今日推荐深度阅读
推荐：《Agency and Agents》—— Ethan Mollick (One Useful Thing)

为什么今天推荐这篇：在 Anthropic Fable 5.1 发布、DeepSeek 大举招聘 Harness 团队、Agent 安全治理融资 5000 万美元的今天，Ethan Mollick 这篇关于“代理权与智能体”的深度思考恰逢其时。当 Agent 能力快速提升，我们需要的不仅是技术基础设施，更需要理解“代理权”的本质——人类将多少决策权让渡给 Agent，以及这种让渡的边界在哪里。

3 个核心观点：
· 代理权是连续的，不是二元的——Agent 从“辅助建议”到“自主执行”之间存在大量中间状态，产品设计需要明确每一步的代理权边界
· 当前 Agent 系统的最大风险不是能力不足，而是能力与代理权不匹配——给低能力 Agent 过多自主权会导致灾难性错误，反之则浪费能力
· 组织部署 Agent 时，真正需要设计的是“人机协作流程”而非“Agent 替代方案”——就像亚马逊的“暮光工厂”概念，人类和机器在各自擅长的环节发挥作用

适合谁读：AI 产品经理、Agent 系统架构师、正在考虑部署 Agent 的企业技术负责人
大致阅读时间：15-20 分钟
