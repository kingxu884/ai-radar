🔬 值得深挖的论文/报告
1. Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness?（arXiv:2610.00025）
核心贡献：构建 4 类 Harness 微任务（自动审批 shell 命令、写记忆、选择工具、排序历史），并预设实践者阈值；扫描 Qwen3 0.6/1.7/4/8B，发现现成 SLM 存在“eligibility gap”，并评估量化对结论的影响。
为什么值得读：它提供了一套可直接复用的方法论，帮助团队判断哪些微任务能安全下放到小模型，而不是盲目用 frontier LLM。对控制成本、降低延迟、提高可审计性极具实操价值。
2. What Should an Agent Remember? Disentangling Retention from Retrieval in Bounded-Memory Evaluation（arXiv:2610.00366）
核心贡献：流式回忆基准，分离“保留什么”与“查询时检索什么”。固定访问条件下，query-aware selection 提升 15.5 个百分点；而混合比较可产生 68.7 点的优势，其中 53.2 点来自历史访问差异而非策略本身。
为什么值得读：它纠正了记忆系统评估中的常见混淆。如果你正在设计长期 Agent 记忆，这篇论文能帮你避免把“更多上下文”误判为“更好的记忆策略”。
3. StabilityArc: Decoding Protein Sequence Embeddings into Generalizable Stability Landscapes（arXiv:2610.00742）
核心贡献：将冻结 ESMC-600M 残基表示通过共享 RoPE Transformer 映射为 L×20 突变效应矩阵；在 66 个严格留一蛋白、134,794 个 ProteinGym 变体上达到 0.7134 Spearman，支持跨蛋白迁移预筛。
为什么值得读：它代表 AI4S 从“序列到结构”走向“可迁移性质景观”。对蛋白质设计、酶工程和药物发现中的早期突变筛选有直接指导价值。
📖 今日推荐深度阅读
推荐：Simon Willison —— llm-typesafe 0.1a0
为什么今天推荐：今天 TechCrunch 报道 Amazon 发布 Jev 类决策模型、decision models flood the web。Simon Willison 这篇短文展示了如何用命令行插件快速接入 TypeSafe AI 的 Jev 模型，执行结构化 yes/no “noul”判断与 choice 分类。它是最具可操作性的入口，帮助你立刻理解“决策模型进入 Agent 工具链”意味着什么。
三个核心观点：
1）专用决策模型可以返回结构化概率（如 {"type":"noul","noul":0.99}），非常适合 Harness 中的分类、路由、审批类微任务；
2）通过 llm install llm-typesafe 即可集成，决策模型不需要生成 token，成本低、输出稳定；
3）这代表一种新分工：大模型负责规划与生成，决策模型负责确定性与可阈值化判断。
适合谁读：AI 工程师、Agent 开发者、产品经理、任何正在设计工具调用与审批流程的人。
预计阅读时间：5 分钟。
