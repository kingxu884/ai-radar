arXiv 重磅论文：Agent Harness Awareness——填补工具调用中的"操作性盲区"
发生了什么：论文提出 Agent Harness Awareness 概念，指出 Agent 选择工具时看不到监控、追踪、近期失败等操作信息，引入 trust-separated 设计，在执行关键动作前由 host 提供小型可验证状态快照。
为什么重要：这是对当前工具调用范式的直接挑战。Tool descriptions 告诉 Agent 工具"能做什么"，却不告诉它"现在是否健康可用"。在长时运行的生产 Agent 中，这个盲区会导致 Agent 在工具已失效时持续做出错误决策。该研究用 ToolRoute 基准验证了方案有效性，对 Harness 工程实践有直接指导意义。
关联动态：与 NVIDIA NeMo 的失败转化理念互补——NeMo 做事后改进，Harness Awareness 做事前预防。
arXiv 论文：Agents, Think Only When it Helps——蒸馏中"思考"的价值被系统性质疑
发生了什么：研究者通过独立扰动教师模型的思考与动作，发现在 Agent 蒸馏中，改动或丢弃思考几乎不影响学生模型的最终动作表现。只有当动作本身不包含思考信息时，思考监督才变得重要。
为什么重要：这直接挑战了当前 Agent 蒸馏的主流做法——记录完整思考-动作轨迹用于训练。如果思考在大多数情况下不必要，训练数据构建策略可以大幅简化，成本显著降低。这是 Post-training 领域一个可能改变工程实践的基础发现。

🔬 值得深挖的论文/报告
1. Agent Harness Awareness: Turning Verified Telemetry into Operational Control for Tool-Using Agents (arXiv:2611.05391)
核心贡献：定义"操作性盲区"——工具描述告诉 Agent 能力，但不告诉它当前健康状态。提出 trust-separated 设计：host 在执行关键动作前提供小型、新鲜、可验证的状态快照，同时保留测量、执行、评估和最终派发权限。用 ToolRoute 基准验证。
为什么值得深读：这是 Harness Engineering 最重要的理论贡献之一，直接回答了一个令人困惑的生产问题："Agent 明明有工具却用不好"。对于正在构建 Multi-Agent 系统或 MCP 工具编排的团队，这篇论文提供了可落地的架构模式。工具健康度快照这个想法可以直接在你的 harness 中实现。
2. Who May Overrule the Agent? Evidence-Gated Authority in LLM Review Institutions (arXiv:2611.05390)
核心贡献：研究多 Agent 系统中审查者的权限边界。发现宽泛的覆盖权限会让审查者既修复错误也破坏正确决策。提出"证据门控"：只有在审查者产出机制上有效的约束违反记录和合规修复后，才被允许用建议替换原决策。在 96 个空间策略任务和 96 个组合迁移基准上验证。
为什么值得深读：Multi-Agent 系统中"审查者 Agent"是常见模式，但很少有人认真想过审查权限应该在什么条件下生效。这篇论文用制度管辖权理论给出了一个可操作的答案。对于设计有安全审查环节的 Agent 系统的团队，这是必读。
3. Morpheus.AI: agents autonomously generate, execute and refine virtual tissue models (arXiv:2611.05413)
核心贡献：将 LLM Agent 与 Morpheus 模拟器配对，让 Agent 自主构建虚拟组织模型。在 15 个基准研究中，前沿 LLM Agent 在 2 小时内以低于 4 美元/模型的成本满足了 83-86% 的研究标准，其中 5 个研究没有已发布模型。
为什么值得深读：这是 AI for Science 中"Agent 驱动科研"的典型范式展示。不是用 LLM 做预测，而是用 LLM Agent 作为科学工作流的编排者，自动生成假设、运行模拟、分析结果、迭代优化。对于关注 AI4S 和 Agent 交叉领域的读者，这篇论文展示了 Agent 在科研自动化中最有说服力的场景之一。
