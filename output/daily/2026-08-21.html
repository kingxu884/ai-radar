7. arXiv 论文：Adversarial Review——Subagent 范式下最小化多方协作的代码审查协议
发生了什么：研究者提出 Adversarial Review，一个最小协作的代码审查协议：主编码 Agent 与 reviewer 和 critic Agent 协作，reviewer 评估代码，critic 通过结构化分歧审计审查，再由主 Agent 编辑。在 LiveCodeBench 上达到最高 pass rate。

1. Position: Multi-Agent Systems Should Prioritize Concurrency Control（arXiv: 2608.18092）
核心贡献：将 LLM 多智能体系统的失败模式系统性地映射到数据库领域的经典并发控制异常，包括脏读（stale reads）、丢失更新（lost updates）和不一致结果，指出长 LLM 推理窗口放大了竞态条件的影响。作者主张 MAS 框架应将冲突检测、隔离保证、结构化共享资源访问作为第一类设计关注点。
为什么值得精读：如果你正在设计或重构一个多 Agent 系统，这篇论文提供了从数据库理论迁移过来的具体概念工具，让你能够诊断“为什么多加 Agent 反而变差了”。它把 Harness 工程从经验主义推向工程科学。
2. Monroe: A Molecular Foundation Model for In-Context Probabilistic Inference（arXiv: 2608.18982）
核心贡献：81M 分子的预训练规模（PM6 量子化学数据），立体化学的改进图表示，构象去噪和嵌入去相关等新型训练损失，核心能力是输出概率推断而非点预测。
为什么值得精读：药物发现的瓶颈在于湿实验数据稀少，而 MFM 的赌注是预训练编码的通用化学知识能否在数据受限场景中泛化。Monroe 的 in-context probabilistic inference 思路——让模型基于上下文输出不确定性——对 AI4S 的下游决策质量有直接意义。如果你关注蛋白质设计和药物发现，这篇论文展示了“不确定性校准”如何被纳入分子表征学习。
3. Adversarial Review: Structured Disagreement for Grounded Agentic Code Review（arXiv: 2608.18167）
核心贡献：在两难困境中找到了实践答案：大团队多智能体效率递减，而完全被动的 subagent 失去交互价值。Adversarial Review 用 reviewer + critic 的最小化冲突方案，在 LiveCodeBench 上达到最高 pass rate，证明了“一个审查者 + 一个审计者”足以提供高质量的代码反馈。
为什么值得精读：对正在设计代码 Agent 产品的工程师而言，这篇文章给出了一个低成本的架构参考。它暗示 subagent 的价值不在于数量，而在于引入结构化对抗。如果你在考虑如何让 Claude Code 或 Cursor 类产品更可靠，这个协议可以立即在现有工具链上实验。
