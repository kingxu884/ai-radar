🔬 值得深挖的论文/报告
1. AgentKVShift: Efficient KV Cache Reuse for Agentic Memory Systems (arXiv:2607.21604)
核心贡献：针对 Agent 记忆系统中结构化记忆单元（含摘要、关键词、标签等 LLM 生成的元数据）的 KV 缓存复用问题，提出训练无关的探针引导 KV 残差校正方法。关键洞察：Agent 的记忆单元与 RAG 的原始文段有本质不同——前者包含结构化和元信息，现有 KV 复用方法面对这种结构化记忆时性能退化严重。
为什么值得深读：KV 缓存管理是 Agent 部署成本的核心瓶颈之一。这篇论文直面 Agent 记忆系统特有的技术挑战，对正在构建 Agent 产品的工程师有直接工程参考价值。也是“Harness Engineering”中记忆管理子问题的前沿探索。
2. Procedural Knowledge Is Not Low-Rank: Why LoRA Fails to Internalize Multi-Step Procedures (arXiv:2607.21612)
核心贡献：首次系统证明 LoRA 在多步骤程序性任务上系统性失败，且增加 rank 不仅没有改善反而可能降低性能。实验覆盖旅行预订（14 节点）和 Zoom 配置两个程序性任务，所有 LoRA 配置（r=16-128）任务成功率显著低于全量微调，同时保持了 95-99% 的对话完成率——这意味着模型看起来“对话正常”但实际任务执行失败。
为什么值得深读：这可能是近期对 Agent 训练策略影响最直接的论文。如果 LoRA 确实本质上不适合学习程序性知识，那么整个 Agent 的 post-training 管线需要重新设计。论文暗示程序性知识可能需要更丰富的参数更新模式，这对选择微调策略有直接指导意义。
3. FlowEvo: Self-Evolving Agents through the Co-Evolution of Workflows and Executable Skills (arXiv:2607.21596)
核心贡献：提出训练无关框架，将 Agent 成功执行轨迹自动编译为可复用的“技能记录”（skill records），包含可调用构件和辅助结构化指导，并在技能库中持久化。核心创新在于技能入库的准入机制：接口检查、重放验证、安全性检查。
为什么值得深读：这篇论文直接回应了当前 Agent 系统的核心痛点——每次推理时的成功经验无法沉淀为持久能力。技能准入的质量控制机制（而非简单的日志存储）是工程上可操作的设计思路，对 Agent 产品团队设计记忆系统有直接启发。
