🔬 值得深挖的论文/报告
1. The Memory Trust Gap: Capability-Dependent Failures in Persistent-Memory Agents (arXiv:2609.01852)
核心贡献：系统性地揭示了持久记忆 Agent 的一个根本性失败模式——记忆信任缺口（Memory Trust Gap）。作者设计了两个 suite 区分"没有记忆就不可解决"（Benefit suite）和"权威工具始终持有正确值"（Safety suite）两种场景，在 Qwen3 0.6B/1.7/4/8B 全尺度上发现：模型对陈旧记忆的过度信任并非混乱，而是一种系统性行为——在 Benefit suite 中各尺度模型以 0.92-1.00 的概率回答过时值，在 Safety suite 中陷阱条件下的表现低于无记忆基线。
为什么值得读：这是目前对"Agent 记忆何时有害"最清晰的实证刻画。对于正在构建 Agent 产品的工程师，这篇论文提供了一个可以直接借鉴的评测框架（Benefit/Safety 双 suite 设计）和明确的设计警告：记忆系统必须有独立的"新鲜度校验"机制，不能简单依赖模型自身的判断。对 AI 安全研究者，它揭示了能力提升并不自动解决记忆可靠性问题。
2. Belief-Calibrated Optimization: An Explicit World Model for Agentic Optimization (arXiv:2609.01861)
核心贡献：指出现有编码 Agent 优化器的核心缺陷——每次编辑依据的"信念"（什么出了问题、哪个改变应该有效）是隐式的，存在于模型当前调用的推理中，而非作为持久状态被记录和复用。BCO 方法将这种信念显式地写下来，作为持久状态供后续调用使用，从而让 Agent 的自我改进真正具有连续性。
为什么值得读：这篇论文触及了 Harness 工程中最本质的问题：Agent 的"世界模型"应该存储在哪里？如果每次调用的推理都从零开始，那么 Agent 的改进就是有界的。BCO 的持久信念存储思路与 DeepSeek Harness 团队正在构建的系统在理念上高度一致，是理解下一代 Agent 优化器架构的关键文本。
3. Beyond Context Windows: Persistent Discovery Context for Data-Centric Agents (arXiv:2609.02129)
核心贡献：提出数据 Agent 在规划/执行前反复执行的"发现步骤"（识别相关数据对象）结果应该被持久化复用，而非丢弃。通过三个结构化数据环境验证了持久发现上下文一致地优于仅元数据检索，并暴露了一个可复现的干扰失败模式。在词汇稀疏领域，仅记忆检索甚至超越了元数据检索。
为什么值得读：这与用户关注的"上下文管理"直接相关。当前 Agent 系统的上下文窗口管理大多聚焦于"如何压缩/裁剪对话历史"，但这篇论文指出了一个被忽视的维度：任务发现过程中的数据上下文化结果本身就是一个宝贵的、可跨会话复用的记忆层。对构建企业数据 Agent 的产品经理来说，这是设计决策的依据——是否应该为每个企业客户维护独立的"发现上下文"记忆库。
