第三部分：🔬 值得深挖的论文/报告
《Speculative Macro Commit for Faster Tool-Using Agents》 [arXiv:2609.03236]
核心贡献：提出 SMC（Speculative Macro Commit），一种双层 agent 系统的运行时机制：大型权威模型产生正式轨迹，小型投机模型在隔离环境快照上持续预测并执行未来动作链。通过从训练轨迹中挖掘重复的多动作骨架并存入宏库，在运行时匹配草稿模型预测的动作链，显著减少串行工具调用带来的墙上时钟延迟。
为什么值得读：直接解决了 tool-using agent 的推理延迟瓶颈，提供了一个实用且可部署的加速方案，对构建生产级 agent 系统具有直接工程参考价值。
《DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training》 [arXiv:2609.04094]
核心贡献：在无 ground-truth 成功信号（outcome-blind）的设置下，提出 DRACO——动态生成多标准评分细则，在整个轨迹完成任务后评分，并将评分分配回各个步骤，产生细粒度的逐步骤优势信号用于强化学习训练。
为什么值得读：长时域 agent 训练的信用分配是 RL 领域的经典难题，DRACO 将“评分细则”与“奖励分配”巧妙结合，对于需要多步推理和工具调用的 agent 训练具有方法论价值。
《Why Gated DeltaNet Survives 4-Bit Quantization》 [arXiv:2609.04098]
核心贡献：首次实现 Gated DeltaNet（GDN）的 NVFP4 W4A4 量化，在 27B 混合 LLM（48 层 GDN + 16 层 Attention）的 496 层线性层上全部应用 4-bit 量化，在 4K/32K 困惑度、MMLU-Pro、GSM8K、AIME'25、GPQA-Diamond、LiveCodeBench 和 RULER 64K 检索等任务上匹配 BF16 精度，同时成为最小（17.5 GiB）和最快预填充（+14-19%）的配置。
为什么值得读：打破了“循环层的量化误差会在长上下文中累积”的直觉假设，为线性注意力模型在实际部署中的压缩提供了关键实验证据，对边缘部署和推理优化有直接工程价值。
