🔬 值得深挖的论文/报告
1. EngramRAG: Dynamic Usage-Weighted Topology and Synaptic Consolidation for Multi-Hop Agentic Memory（arXiv 2609.32049）
核心贡献：基于互补学习系统原理，提出 Waking State 低延迟反射 + Dreaming State 异步背景整合的双层记忆架构。引入 Usage-Modulated Personalized PageRank 让转换概率通过赫布式可塑性自适应演化，解决多跳关系遍历和持久身份信息保留问题。
为什么值得读：Agent 记忆目前是 Harness 工程中最混乱的环节。这篇论文系统性地诊断了三种失败模式（关联盲区、脚手架健忘、静态拓扑停滞），并给出了可落地的架构方案。如果你在构建多会话 Agent 系统，这篇论文的 U-PPR 设计可以直接影响你的记忆层决策。
2. Receiver-Conditioned Latent Communication gives 94% CacheBack（arXiv 2609.32046）
核心贡献：多 Agent 系统中的 KV cache 传输存在严重浪费。作者提出接收方条件通信——Agent 只需发送接收方本地任务真正需要的部分。通过让接收方 Agent 传入其任务描述，实现 94% 的 cache 削减。
为什么值得读：多 Agent 系统最大的隐性成本是上下文传输。这篇论文把"按需传输"从哲学原则变成了可量化工程实践。94% 这个数字意味着多 Agent 编排的 GPU 内存成本可以降低一个数量级，对任何做 Multi-Agent 架构的团队都是必读。
3. M3OS: A Monte Carlo Graph Search-Orchestrated Multi-Agent LLM System for Evidence-Traced Molecular Optimization（arXiv 2609.34491）
核心贡献：将小分子优化中的药物化学推理与优化状态管理解耦。用持久图结构连接评估候选分子、父子转换关系与评估证据，LLM 辅助父节点选择，工具驱动的候选生成与评估分支并行。
为什么值得读：这是 AI for Science 领域 Harness 设计的优秀范例。它解决的痛点是：对话上下文无法有效管理多轮分子优化的状态——候选分子身份、历史评估、约束条件。对深势科技、晶泰科技等从事 AI 药物发现的公司有直接参考价值。也值得与同日发布的 BioDyad（2609.31939）论文对照阅读。
📖 今日推荐深度阅读
Lilian Weng：《Harness Engineering for Self-Improvement》（2026-07-04）
链接：https://lilianweng.github.io/posts/2026-07-04-harness/
为什么今天推荐：DeepSeek Harness 团队急聘人才、NVIDIA 发布 Agent Safety Platform、多篇 Harness 相关论文同日出现——今天的所有信号都在指向同一个结论：模型改进的杠杆正在从权重调优转向外围系统工程。Lilian Weng 这篇文章是理解这一转变的最佳入口，它把递归自我改进从哲学讨论拉回到了具体的工程循环。
核心观点：
• 现代 AI 中的 RSI 循环不意味着模型直接修改自身权重，而是模型改进训练管道和部署系统，进而产生更优的下一代模型
• Harness 工程是自我改进循环的瓶颈——模型需要可靠的环境来从错误中学习，而环境本身的设计质量决定了改进的收敛速度
• Agent 评估与奖励设计决定了自我改进循环是收敛还是退化——如果评估信号有噪声，改进循环会放大错误而非纠正错误
适合谁读：正在构建 Agent 系统或思考 Agent 产品化的工程师、产品经理、研究员。尤其适合关注 DeepSeek Harness 动态的读者。
大致阅读时间：20-25 分钟。
