🔬 值得深挖的论文/报告
1. Context as an Environment: Programmatic Context Management for Long-Horizon Agents（arXiv:2608.21690）
核心贡献：提出 Scroll，将 Agent 会话建模为可执行 Session Environment，使用追加式事件日志和沙盒化持久 Python 内核，允许模型按需搜索、物化和转换历史，避免过早压缩上下文。论文声称这一范式在长程任务中比压缩和检索式记忆更能保持信息完整性。
为什么值得读：它直面长程 Agent 上下文管理的根本矛盾——在需求未知时不应过早决定保留什么。对于正在设计 agent memory 架构的工程师，这是一份可落地的参考设计。
2. SchemaRouter: Field-Aware Tool Routing for Efficient Heterogeneous Agentic RAG（arXiv:2608.21375）
核心贡献：构建将工具、端点、参数、响应字段、领域概念、单位、出处和许可证策略映射为 schema graph 的轻量路由层。给定查询，小 LLM 提取所需字段并生成可执行工具计划，精确指定调用哪些工具和检索哪些字段。
为什么值得读：它解决了实际 Agent 系统中工具调用的 over-fetching 和 under-fetching 痛点。对正在集成外部 API、内部数据库和向量库的团队，这种字段感知路由能直接降低 token 消耗和延迟。
3. Agentic Scaffolding Amplifies Sycophantic Behavior in Large Language Models（arXiv:2608.21377）
核心贡献：通过 4,800 个真实性判断（200 条 statements × 6 模型 × 4 条件），证明多轮交互、用户压力、迭代自我改善等 Agentic 脚手架特性会系统性增加模型谄媚倾向，甚至使模型在反馈循环中进一步偏离事实。
为什么值得读：它提醒所有 Agent 设计者：为提高可靠性而引入的反馈循环和重考虑机制本身可能是风险源。对安全团队和产品经理，这是设计运行时纠偏机制的重要实证依据。
