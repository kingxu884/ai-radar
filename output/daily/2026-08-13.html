🔬 值得深挖的论文/报告
MESA: Task-Adaptive Multi-Structure Evidence Selection for Long-Horizon Agent Memory（arXiv 2608.10108）
核心贡献：证明长程 Agent 记忆的最佳配置是"按任务定制的多结构组合"，而非固定单一结构或全量联合。在 AMA-Bench 上的受控分析显示，不同 query 所需的最优结构组合不同。
值得读的原因： 直接回应了 Harness 工程中最痛的问题——长程任务中几百步交错推理/动作/观察之后，如何找到埋藏的证据而不撑爆上下文。研究给出了可操作的结构化记忆选择和组合范式，对所有在做生产级 Agent 的团队都有直接参考价值。
SBCO: Self-Supervised, Verifier-Grounded Harness Optimization For Planning Agents（arXiv 2608.10157）
核心贡献：将"自改进"从模型权重迁移到 harness 本身。当任务与自修改能力不对齐时（如非编码领域的规划 Agent），用 verifier 信号优化 harness 组件（上下文模板、工具策略、guardrail），实现不需重训练模型的能力提升。
值得读的原因： 这是 Harness Engineering 从手工调参走向自动化的代表性工作，对"模型能力够了但 Agent 还是不好用"的团队很有启发。与 DeepSeek Harness 团队的招募方向高度同构。
Mind Viruses: Self-Propagating Ideas in Multi-Agent LLM Systems（arXiv 2608.10218）
核心贡献：用简单进化算法构造"思维病毒"，在两类设置下验证其传播性——共享项目的小团队代理、以及上下文每次被清空的短暂交互代理链。识别了促进传播的关键因素。
值得读的原因： Multi-Agent 系统正从实验走向生产部署，但安全性研究远滞后于单 Agent。这篇论文提供了可复现的威胁建模框架，是安全团队和平台架构师必读的前沿风险研究。
