🔬 值得深挖的论文/报告
1. TRACE: Transition-Aware Residual Control for Multi-Objective Materials Discovery（arXiv:2608.23631）
核心贡献：提出将"编辑操作"而非"候选材料"作为反馈基本单元，通过记录 parent-edit-child 的属性变化增量，让 Agent 在竞争性多目标优化中做出更精准的局部调整。这解决了当前 LLM Agent 在材料发现中"知道什么成功但不知道为什么成功"的问题。
为什么值得读：对做 AI for Science Agent 的团队，TRACE 的 Transition-Aware 思路可以迁移到蛋白质设计、分子优化等场景。它实际上是在非梯度优化中引入了一种"经验梯度"。
2. RENDER: Controlling Reader-Facing Evidence in LLM Memory Evaluation（arXiv:2608.23568）
核心贡献：将记忆评估的控制变量从"对话内容"转向"呈现给 Reader 的 artifact"——Memory entry、Summary、Typed Record、Raw Excerpt 的渲染方式本身影响模型表现高达 24.6-48.8 分。
为什么值得读：对于在 Harness 中设计记忆层架构的工程师，这篇论文揭示了一个关键盲区：同样的对话历史，用不同格式渲染给模型，效果差异巨大。影响直接关系到 MemGPT 风格系统的设计选择。
3. AgentRoom: Concurrent Multi-Agent Coding in a CRDT-Backed Shared Workspace（arXiv:2608.23740）
核心贡献：提出基于 CRDT 的实时协作编码协议，让多个 Agent 在文件级粒度上并行工作，解决了当前 Multi-Agent 编码系统"串行 handoff"或"无协调并行"的通病。
为什么值得读：如果你在构建 Multi-Agent 编码系统或评估 Claude Code 的架构演进方向，这篇论文的 CRDT 方案（文件级 claim、实时同步）代表了一种从人类协作工具借力的工程思路。单 Agent 在困难任务上半数失败于"stub-and-exit"，多 Agent 并发是解决方案。
