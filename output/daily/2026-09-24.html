🔬 值得深挖的论文/报告
1. FIRE: Failure-Informed Runtime Engineering for Reliable Language-Model Agents
核心贡献：提出一种系统化的运行时策略框架——在观测到失败状态前应用目标化的自然语言指令和动作拒绝，不改变模型权重。在 Terminal-Bench 2.1 全部 87 个任务上，Sol 档位 pass² 从 64.4% 提升至 73.6%，而 best-of-two 仅变化 1.2 个点，证明策略的核心作用是提升一致性而非峰值能力。
为什么值得读：这是 Harness 工程最直接的方法论突破。它将"失败模式"从被动诊断变为主动干预的触发条件，为 Agent 产品化提供了可工程化实施的可靠性路径，且数据完整、实验设计严谨。如果你只精读一篇今日论文，选这篇。
2. How Strongly Should Task State Influence an LLM Agent?
核心贡献：系统比较了任务状态传递给 agent 的四种强度——原始 transcript（状态被展示）、精确 checklist（状态被告知）、状态机每轮指令（状态被编译）、强制门控（状态被强制执行）——在固定规则、模型和配对 episode 下分离了可靠性的来源。
为什么值得读：Long-horizon Agent 任务的状态管理是 Harness 架构设计的核心决策。这篇论文回答了"可靠性多少来自信息展示、多少来自强制执行"，为 Harness 引擎设计（状态机 vs. prompt 管理）提供了第一性原理分析。
3. ToolCompass: Guiding Tool Trialing, Not Suppressing It
核心贡献：用 von Mises-Fisher 分布组织工具调用表征，按共享功能联合减少跨域 intra-function variation 并增加 inter-function separation，从而引导而非压制 LLM agent 对未见工具的工具探索（tool trialing）。
为什么值得读：工具调用的"探索-利用"平衡是 Agent 泛化能力的瓶颈。现有方法要么浪费交互预算（过度探索），要么压制必要探索（过度约束）。这篇论文提供了可操作的表示学习方法，对工具注册表设计和工具调用后训练都有直接指导价值。
