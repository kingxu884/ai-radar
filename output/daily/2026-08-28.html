🔬 值得深挖的论文/报告
1. Same Model, Different Harness: Different Coding-Agent Results (arXiv:2608.26218)
核心贡献：首次在固定模型和任务的情况下，系统性地量化 Harness 配置变化对 Coding Agent 结果的影响。通过缩短旧工具结果、响应停滞工作等机械操作，在 SWE-bench Verified 和 Pro 上均观察到完整解决方案数量的提升。论文提出了 F2PF（fail-to-pass fraction）作为更细粒度的衡量指标。
为什么值得读：这是目前最直接的 Harness 工程实证研究，为 Agent 产品团队提供了可操作的上下文管理策略，也是理解 Harness 与模型能力边界的关键数据点。适合正在构建或优化 Coding Agent 的工程师和产品经理。
2. Agents Don't Paginate: First-Chunk Selection for LLM Tool Responses (arXiv:2608.26130)
核心贡献：基于公开 MCP 中间件的 session logs，发现 Agent 从不主动请求工具结果的第二页，只读取第一块数据。论文将 first-chunk selection 建模为 0/1 knapsack 问题，在 500 个 SWE-bench Verified 任务上比较了 6 种价值函数的 precision-at-1 性能。
为什么值得读：如果你正在构建高频工具调用的 Agent 系统，这篇论文揭示了一个被普遍忽视的隐性瓶颈——工具返回的黄金信息是否排在第一块。改变排序策略可能比升级模型带来更直接的性能提升。
3. RegimeFormer: A Large Protein Model of Global Perturbation Regimes (arXiv:2608.26586)
核心贡献：构建了包含 202,556,313 个非冗余蛋白质序列的 RegimeAtlas，训练了一个大型蛋白质扰动模型，能在氨基酸残基级别预测突变响应，与深度突变扫描、分子基准和结构置信度均有良好对齐。
为什么值得读：这是蛋白质语言模型从"序列理解"走向"扰动预测"的重要一步。对于从事蛋白质设计、药物发现或合成生物学方向的研究者，这个模型提供了突变效应预测的新基线，其 RegimeAtlas 数据集本身也极具复现价值。

崔添翼《Harness 的思考：Model + Harness = Agent》（知乎专栏）
为什么今天推荐：DeepSeek Harness 团队今天正式进入公众视野，崔添翼作为负责人，他的产品哲学直接决定了这个团队的方向。在 Agent 竞赛进入 Harness 工程化阶段的当下，这篇来自一线实践者的系统思考是最有价值的第一手资料。

• Model 能力决定了 Agent 的上限，但 Harness 的工程质量决定了能释放出多少模型潜力——两者是乘法关系而非加法关系。

• 终端入口的控制权至关重要：谁掌握真实项目中的工程试错轨迹，谁就能将 Harness 数据反哺到模型进化闭环中。
适合谁读：Agent 产品负责人、Harness 工程师、AI 基础设施团队、关注 DeepSeek 战略方向的研究者。
