🔬 值得深挖的论文/报告
1. Meta-Harness: End-to-End Optimization of Model Harnesses (arXiv:2603.28052)
核心贡献：提出了对 Harness 本身进行端到端优化的框架，将 Harness 视为可学习的组件而非固定配置。作者包括 Stanford 的 Omar Khattab（DSPy 作者）和 Chelsea Finn。
为什么值得读：这标志着 Harness Engineering 从"手工调参"向"自动优化"的范式转变。如果你正在设计 Agent 系统，这篇论文提供了将提示词、工具选择和循环策略统一优化的方法论，可能成为 Harness 领域的"DSPy 时刻"。
2. Natural-Language Agent Harnesses (arXiv:2603.25723)
核心贡献：系统性地将自然语言作为 Agent Harness 的配置界面，探索通过自然语言描述来定义工具权限、上下文策略和执行循环。
为什么值得读：如果自然语言能直接配置 Harness，将大幅降低 Agent 系统的使用门槛，同时为"非程序员驱动 Agent"的产品方向（如阿里 Qoder）提供理论基础。
3. In-Context Prompting Obsoletes Agent Orchestration for Procedural Tasks (arXiv:2604.27891)
核心贡献：提出对于程序化任务，上下文提示（In-Context Prompting）可以替代复杂的 Agent 编排层，挑战了 Harness 对复杂编排的依赖假设。
为什么值得读：这是一篇反直觉的论文。当整个行业都在向更复杂的 Agent 编排投入资源时，这篇论文提醒我们：对于确定性任务链，简单的上下文提示可能比多 Agent 编排更高效、更可靠。值得所有 Harness 工程师思考：哪些场景真正需要编排，哪些是过度工程化。
