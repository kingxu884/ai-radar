🔬 值得深挖的论文/报告
CAMeR: Keyword-Gated Hybrid Activation for Adaptive Memory Retention in LLM Agents (arxiv 2607.20458) 核心贡献：提出结合符号级（Jaccard）和亚符号级（embedding cosine）的门控机制，让 Agent 自动判断哪些记忆值得强化、哪些应该衰减，并提供 CAMeR-Bench 评测集（76 条记忆、100 轮对话）。 为什么值得深读：记忆管理是 Agent 工程中最棘手的工程问题之一。该论文不仅提出算法，还给出了可用于横向对比的 benchmark，直接服务于工程落地。与 Pulsar Attention（2607.20457）的成本优化思路形成互补。
THOR: A Theta-Gamma Hierarchical Oscillatory Reasoning Framework for Multi-hop QA (arxiv 2607.20459) 核心贡献：借鉴神经科学的 Theta-Gamma 振荡机制，将多跳推理分解为"全局规划+局部检索"的双层架构，并加入验证修复机制阻断错误传播。 为什么值得深读：该论文代表了一种趋势——从认知科学和神经科学中汲取 Agent 架构设计灵感。如果能在工程上高效实现这种分层推理，将显著提升 Agent 在复杂多步任务中的可靠性。
Sample-Efficient Learning from Agent Experience (arxiv 2607.21051) 核心贡献：提出 Experience Distillation 方法，让 Agent 在无需额外环境交互的情况下，将交互历史中的经验内化到模型权重中，解决了上下文学习的经验遗忘问题。 为什么值得深读：该论文直击 Agent 部署的核心痛点——如何让模型从历史错误中持续学习而不增加推理成本。与 DeepSeek 将 Harness 轨迹注入模型进化的思路高度一致，是理解 Agent 持续学习机制的关键文献。
