趋势三：多智能体系统的安全与治理从"未知风险"变成"正在发生的问题"
证据链：① Anthropic 的实验公开了 AI Agent 之间的冲突、共谋与协调行为；② arXiv "Dynamic Governance of Multi-LLM Agent Systems" 发现双 Agent 对立目标下系统会"崩溃而非竞争"；③ "Conformity Mitigations" 测量了 23 个模型在面对错误多数意见时的盲从率（MMLU 22.8%，SimpleQA 高达 71.0%）；④ "The Off-Support Barrier" 从理论层面论证安全约束不是学习问题不变量。
预判：单 Agent 的安全评估框架正在失效。做 Multi-Agent 架构的团队需要从"依赖单体对齐"转向"设计系统性治理机制"——投票、仲裁、审计追溯、退出机制。不做这一步的厂商，将在生产环境中遭遇无法复现的"集体失灵"。
🔬 值得深挖的论文/报告
1. Lost in Compaction: Evaluating Side-Constraint Loss under Context Compaction（arXiv:2608.11242）
核心贡献：系统性地量化了一个关键工程问题——当上下文压缩发生时，用户的会话级约束被静默丢弃的比例。覆盖多轮对话、agentic 轨迹和长程研究三种场景，发现平均仅保留 17% 的约束。
为什么值得读：这是"上下文管理"这一 Harness 核心能力中最被忽视的盲区。论文不是泛泛谈论"压缩导致性能下降"，而是精确识别了一个特定类型的失败模式——用户显式约束的丢失——并给出了量化的严重程度。对于任何做长程 Agent 产品的团队，这是一份可以直接指导设计评审的清单。
2. Harnessing agent memory to build lifelong AI partners for materials scientists（arXiv:2608.11224）
核心贡献：提出将材料科学 AI 伙伴设计为"围绕持久记忆而非特定 Agent 实现"的框架——以可检查的事实和可执行的技能存储科学经验，跨越多个 Agent 实例保持可移植性。
为什么值得读：它将 AI4S 与 Agent Harness 关注点完美结合。论文拒绝"为每个新任务重新训练 Agent"的范式，主张将科学经验沉淀为可审计、可复用、可跨平台迁移的记忆结构。对做 AI4S 产品化（尤其是与实验科学家协作）的团队，这提供了一个非常有操作性的架构蓝图。
3. Towards the Harness of Embodied Agents（arXiv:2608.11246）
核心贡献：提出 Thea——将编程 Agent 的 harness 范式扩展到物理世界的 embodied agents。核心创新是"Scene Graph as Context"（场景图作为持久符号世界表征）和"Evaluation as Exit Codes"（执行评估）。
为什么值得读：它是通往"物理 AI 基础设施"的重要理论桥。论文清晰地指出了 software agent 与 embodied agent 之间的两个鸿沟——无法免费读取世界状态、无法免费判断动作结果——并给出了具体的设计应对。对于正在从纯软件 Agent 向机器人/物理交互延伸的团队，这是一份可操作的设计哲学文档。
