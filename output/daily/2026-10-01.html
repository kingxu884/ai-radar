🔬 值得深挖的论文/报告
1. Self-Evolving Harness on Multiple Tasks with the Agent as Its Own Optimizer (arXiv:2609.38372)
核心贡献：提出让同一冻结模型既作为求解器又作为提议者，在多个任务上自进化 harness，避免为每个基准单独演化。框架接近递归自我改进，覆盖现实多域任务。
为什么值得读：这是 harness 自动化方向的代表性工作，直接回应用户对上下文管理、工具调用、记忆等核心机制的关注，为构建跨任务通用 agent 提供新思路。
2. MILO: Automated Harness Discovery via Orchestrated Multi-Agent Evolution (arXiv:2609.38349)
核心贡献：引入“元进化岛屿编排”，共同进化 agent harness 与发现策略，使用层次谱系记忆和每岛变异 agent，避免固定搜索策略的局限。
为什么值得读：解决了 harness 搜索空间组合爆炸与模型更新后需重新设计的问题，对实践者设计长时程 agent 系统具有直接参考价值。
3. A Competing-Hazards Systematization of Loss of Control in Autonomous Agents (arXiv:2609.38411)
核心贡献：用离散时间竞争风险模型统一描述 agent 尝试的四种结局（批准完成、安全停止、范围逃逸、继续），推导重试预算内的逃逸概率与安全预算限制。
为什么值得读：为近期多起 agent 失控事件提供了可量化的安全分析框架，适合安全团队与产品负责人在部署前进行风险建模。
