🔬 值得深挖的论文/报告
1. Deployment Decision Reliability: A Generalizability-Theory Framework for Sizing Long-Horizon Agent Evaluations (arXiv:2608.11323)
核心贡献：用四因子 G-theory 方差分解（Henderson Method-I、REML、贝叶斯 GLMM 三种估计器一致到小数点后三位）证明 agent 主效应 <3%。进一步发现最难四分之一任务上聚合信度崩溃。
为什么值得读：这是第一篇把心理测量学的 G-theory 严格应用于 Agent 评估的论文。它提供的不是"又一个排行榜"，而是一套评估评估本身的方法论。对于需要为团队或公司建立 Agent 准入标准的人，这篇论文给出了"你需要多少任务、多少重复、多少评估者"才能做出可靠决策的数学答案。
2. Harness-IF: Evaluating Instruction Following Across Instruction Surfaces in Coding Agents (arXiv:2608.11727)
核心贡献：提出 Against-Prior Accuracy 来分离"真正遵守规则"和"碰巧做对"。在 5 个可配置表面上测试 256 条规则，用 9 个 probe builds 建立 baseline。
为什么值得读：这是目前最接近"Claude Code 工程师实际工作"的评测框架。它回答的问题非常务实：规则写在 system prompt、memory 文件、项目配置、还是工具描述里，对执行结果有什么差异？正在构建 Coding Agent 的团队可以直接借鉴其方法学来优化自己的指令放置策略。
3. The Sleeping Agent: What Gist-Based Context Compression Loses and Why (arXiv:2608.11775)
核心贡献：用 Salience-Weighted Consolidation（受睡眠记忆巩固启发的压缩框架）作为诊断探针，在 LoCoMo 的 10 个对话上评估 1,935 个匹配问题，发现 gist 压缩对不同记忆类型（语义/情节/程序性）的检索影响截然不同。
为什么值得读：长上下文 Agent 的上下文管理是 Harness 工程的核心难题。这篇论文不提供又一个压缩算法，而是诊断"压缩什么时候有害"。结论暗示我们对历史对话的压缩策略需要按记忆类型分层，而非一刀切 summarization。对做长时间运行 Agent 的团队有直接指导价值。
