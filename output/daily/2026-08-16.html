🔬 值得深挖的论文/报告

1. Governed Persistent Memory: Source-Bound State Semantics and Fail-Closed Release for Long-Horizon Agents (arXiv:2608.12476)

核心贡献：提出 GPM 可审计双时态状态转移模型，实现来源绑定准入、派生生命周期状态、公共屏障与 fail-closed 结构化释放；在 3,600 案例的 GPM-ReleaseBench 上匹配所有完整结果。

为什么值得读：大多数 Agent 记忆系统只解决“存取”，不解决“撤回/删除/过时信息是否有权支持后续声明”。该论文给出可落地的记忆治理语义与基准，对生产环境可信 Agent 极有参考价值。

2. SteerBench-Work: A Benchmark for Agent Steering at Action Boundaries (arXiv:2608.12654)

核心贡献：事件锚定、双向的 106 场景基准，覆盖开发运维、客服、金融、法律、医疗、HR、安全；每个场景判断“继续执行”或“移交人工/策略审查”，两种错误方向样本接近均衡。

为什么值得读：Agent 产品化的核心风险是“一步就能发邮件、合并 PR 或付款”。该基准把预提交转向决策变成可量化问题，适合产品经理、安全工程师和 Agent 平台设计者理解边界控制。

3. Beyond the Best Guess: Improving LLM Solution Coverage with Evolution Strategies (arXiv:2608.12679)

核心贡献：发现标准 RL 后训练会收窄模型输出分布，导致 pass@k 解空间覆盖坍缩；改用进化策略（ES）可保持候选解多样性，更适合数学与科学发现等探索型任务。

为什么值得读：对 AI4S、算法发现、药物分子设计等场景，探索能力比单次最优解更重要。论文直指当前 post-training 目标与发现任务之间的错配，提供可操作的替代方法。

📖 今日推荐深度阅读

Rich Sutton: The Bitter Lesson

为什么今天推荐：在 Harness 工程、插件化、人工约束设计空前繁荣的今天，Bitter Lesson 提醒我们：通用计算与规模最终会超越手工先验。阅读它有助于在构建复杂 Agent 运行时之际，分清哪些工程约束是必要的安全/审计边界，哪些可能成为阻碍可扩展学习的“人类先验”。

三个核心观点：

  • 大规模算力与通用学习方法在长期永远胜于领域知识的手工编码。
  • 研究者应专注构建可随算力扩展的方法，而不是固化当下的领域洞察。
  • 搜索与学习是核心机制，手工特征/规则终将被通用模型取代。

适合谁读：Agent 工程师、AI 产品决策者、研究员。大致阅读时间：15 分钟。
