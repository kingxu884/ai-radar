🔬 值得深挖的论文/报告
1. 《Measurement Without Validity: The Compounding Reliability Problem in Agentic AI Evaluation》
核心贡献：提出了一个“三层复合效度模型”，揭示了当前 AI 评测流水线（从任务设计到指标聚合）是如何系统性崩塌的。它给出了一个可操作的诊断工具，提醒从业者区分“看起来很好”和“真的有用”。
为什么值得读：如果你正在搭建 Agent 评测系统，或者需要根据 Benchmarks 做采购决策，这篇论文是必读的防坑指南。它解释了为什么你的 Agent 在排行榜上高分，但在实际业务中却表现不佳。
2. 《TrAC: Trace-Conditioned Answer Consistency for Efficient Uncertainty Quantification in LLMs》
核心贡献：不同于传统的多次采样法，该方法通过让模型在生成推理轨迹后，再次基于该轨迹生成答案，以此来量化模型的不确定性。这是一种极低成本的 LLM 置信度诊断方案。
为什么值得读：对于构建 Agent 的工程师来说，知道模型何时“不确定”是触发人工干预或切换策略的关键。TrAC 提供了一种不影响推理速度的实时不确定性检测机制，非常适合在 Harness 层中实现。
3. 《Expanding Protein Structure Prediction into Conformational State Space》
核心贡献：该论文指出，单一的静态结构预测已不足以理解蛋白质功能，必须将预测任务重构为“状态空间推断”问题，揭示蛋白质的动态构象态及其能量关系。
为什么值得读：这是 AI 药物设计（AIDD）的下一阶段核心。理解蛋白质的态变（conformational states）是药物靶点发现和别构药物设计的关键。这篇论文指明了 AI 生成模型与物理模拟融合的方向，是深势科技、分子之心等国内 AI for Science 玩家必须跨越的技术门槛。

1. 无状态化是 MCP 的救赎：MCP 1.0 的复杂状态管理是它被 Skills 和 curl 脚本取代的命门，而 2.0 的无状态架构使其轻量到足以嵌入任何 Agent 工具链。

3. API 的消亡与工具的崛起：MCP 代表了从 LLM 调用 API 到 LLM 使用工具的进化，这是 Agent 自主性的关键一步。
适合谁读：所有正在构建 Agent 工具的开发者、正在集成 MCP 的系统架构师、以及关注 AI 基础设施标准化的产品经理。
