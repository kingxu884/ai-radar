🔬 值得深挖的论文/报告
1. MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents (arXiv:2611.07689)
核心贡献：首个系统诊断 MCP Agent 在推理、执行和记忆三个维度幻觉风险的基准，覆盖 358 个任务和 36 个生产 MCP 服务器。每个任务设计有结构性触发器，可精确定位四类失败模式。
为什么值得读：MCP 生态快速扩张但缺乏系统评估，该基准直接针对生产环境中最棘手的 Agent 可靠性问题。如果你正在构建或评估 MCP Agent，这篇论文提供了可操作的诊断框架。
2. The Harness Is the Model: Agent Scaffolding Changes a Fixed LLM's Compliance with Banking Conduct Rules (arXiv:2611.06116)
核心贡献：通过 156 个预注册案例实验证明，同一模型在 5 种不同 Harness 架构下对银行合规规则的表现差异显著。Harness 设计选择（工具循环、记忆结构、合规审查者角色）对最终行为的影响不亚于模型选择。
为什么值得读：为“Harness Engineering 是独立学科”提供了实证基础。金融、医疗等强监管行业的 Agent 构建者必读。
3. Don't Prompt Your Agents. Equip Them: Skillware as a Modular Standard for Sovereign, Auditable, and Deterministic Capability Execution (arXiv:2611.07652)
核心贡献：提出 Skillware 框架，将 Agent 能力封装为模块化、版本化、可审计的软件包，替代脆弱的 Prompt 工程。类比游戏中的技能热键——Agent 调用的是经过验证的确定性能力，而非动态生成的代码。
为什么值得读：直接挑战当前 Agent 架构的主流范式。如果你对 Agent 的可靠性、可审计性和成本控制有要求，这篇论文提供了全新的架构思路。
