Grounding Agent Memory: Environment-Probing Curation for Enterprise Agents (arXiv:2609.11060)
核心贡献：提出“环境探测式策展”（environment-probing curation），在不重新训练模型、不改变生产写入权限的前提下，让异步策展 agent 使用只读工具验证、限定范围并刷新候选记忆。在 GitHub Copilot harness 上进行了生产级对比实验。
为什么值得读：这是少见的直接将记忆治理落地到真实开发工具 SDK 的研究。对于正在构建或使用持久记忆 Agent 的工程师，它提供了一个可操作的“记忆健康检查”架构范式，直接回答了“如何防止 Agent 记住错误的东西”这一工程难题。
Defining AI Agents: A Compendium of Criteria, Metrics, and Benchmarks (arXiv:2609.11018)
核心贡献：构建了一个五维 agenticness 框架（环境交互、学习适应、自主性、目标导向、时间连贯性），并对每一维度的度量与基准做了系统综述，明确指出评估中“有限且不一致”的区域。
为什么值得读：当团队内部对“这是不是 agent”争论不休时，这篇论文提供了统一的认知框架和评估谱系。特别适合产品经理和研究员在定义 agent 产品边界、设计评估方案时作为参考底稿。
An Open Recipe for IMO Gold: Training Nemotron for Olympiad Mathematics (arXiv:2609.10712)
核心贡献：从 Nemotron 3 Ultra 出发，通过 SFT + RL 训练数学专家模型，构建了完全自然语言的测试时计算 pipeline，不依赖形式化证明器或外部工具。系统通过生成-验证-精炼的迭代搜索，在 IMO 级别问题上取得金牌级表现。
为什么值得读：它证明了高质量推理能力的提升可以通过“开放模型 + 精心设计的测试时搜索”实现，而无需依赖封闭的前沿 API。对于关注 Post-training 和推理能力栈的从业者，这篇论文提供了可复现的训练配方与验证策略。
