🔥 今日必读
ClawLoop：Harness 原生的自改进训练循环（arXiv 2610.14118）
发生了什么：一篇重磅论文提出 ClawLoop，让 Agent 在自身 Harness 环境中通过“训练循环”实现自我改进，不再依赖更强外部模型合成任务和收集轨迹。
为什么重要：当前 Harness 型 Agent 的 post-training 管线几乎全部是 one-shot 且 teacher-dependent——外部模型出题、收集轨迹、训练一次、人工评估，能力上限被外部模型和人类先验锁死。ClawLoop 把 Harness 本身变成训练基础设施，让 Agent 在沙箱文件系统与 Shell 交互中持续产生训练信号，是 Harness 工程从“执行容器”升级为“学习系统”的关键信号。
关联：与 Harness^2（递归 Harness）、Reels-RSI（程序级自改进）、HERO（Harness 证据优化）形成今天 arXiv 上罕见的“Harness 自改进集群”，同时呼应崔添翼“Model + Harness = Agent”的产品哲学。
Harness²：面向开放世界的递归 Agent Harnessing（arXiv 2610.14224）
发生了什么：该工作提出 Harness²，通过两层递归（任务级递归 + 元级递归）解决开放世界中 Harness 自改进的两大难题：缺少 ground-truth verifier 和任务特异性过强。
为什么重要：RSI（递归自改进）在封闭任务中有效但难以泛化到新场景，这是 Agent 落地真实生产环境的核心瓶颈。Harness² 的 plug-and-play 设计让 Harness 本身可以随任务演化，标志着 Agent 工程的重心从“模型 pre-training / post-training”转向“Harness 的 online adaptation”。
关联：与 ClawLoop 形成互补——ClawLoop 解决“谁提供训练信号”，Harness² 解决“如何在开放世界泛化”。两者合起来勾勒出下一代 Agent 栈的完整图景。
MCP 元数据研究：367,174 个工具的大规模干预实验（arXiv 2610.14334）
发生了什么：论文分析 367,174 个 MCP 工具的元数据，发现功能相似的工具共享名称和描述却暴露不同参数 schema，并通过受控因子级干预实验证明参数 schema 差异可以在调用前就影响 LLM 的工具选择。
为什么重要：MCP 生态正爆发式增长，但工具选择完全依赖元数据——名称、描述、参数 schema。如果 schema 的细微差异就能改变选择行为，意味着 MCP server 的元数据设计本身就是一种隐式的 prompt engineering，直接影响 Agent 的工具调用可靠性。这对所有在做 MCP 集成的团队是直接可操作的信号。
关联：与 NVIDIA NeMo Gym 的芯片设计 Agent 工具调用优化、以及“Silent Failures in Agentic Data Science”中对方法论失败的诊断形成呼应——工具层和执行层的可靠性已成为 Agent 工程的核心风险面。
