🔬 值得深挖的论文/报告
《The LLM Proposes, the Executive Disposes: A Self-Verifying Agent Instrument》（arXiv:2608.04066）
核心贡献：提出一种结构性验证的 Agent 架构——确定性“Executive”持有所有信念，LLM 只能提交类型化提案，预测必须预先注册并由代码验证。8 次架构运行中有 4 次因违规而自我失效。
为什么值得读：这是目前对 Agent“信任问题”给出最务实工程方案的论文。不是后验评分，而是从架构层面消除承诺漂移和绑定漂移。对于正在构建生产级 Agent 的工程师来说，Executive-Proposer 分离模式可能是下一个最佳实践。
《SafeCommit: Certifying When Memory-Grounded Agents May Safely Act》（arXiv:2608.04289）
核心贡献：形式化了记忆不确定性下的安全承诺问题，提出一个风险控制层——构造一组可信潜在世界集合，仅当某项动作在所有保留世界中都安全时才执行。
为什么值得读：直击 Agent 记忆管理的核心痛点——陈旧、冲突、不完整的记忆何时该阻止行动？这不只是学术讨论，而是 Claude、GPT 等 Agent 产品在长周期任务中反复翻车的根源。
《Architectural Implications of Agentic AI Workloads》（arXiv:2608.04458）
核心贡献：首次对 Agent 工作负载进行架构特征分析，基于 Microsoft Azure 生产环境研究。揭示 Agent 执行是碎片化和异构的——LLM 推理、工具调用、编排决策反复跨越 CPU-GPU 边界。
为什么值得读：如果你在思考 Agent 基础设施或推理成本，这篇是必读。它解释了为什么 Agent 延迟远高于单次 LLM 调用，并对硬件设计者、框架开发者给出可操作的优化方向。
