🔬 值得深挖的论文/报告
1. Model or Harness? An Interaction-Centric Taxonomy for Localizing Agent Failures (arxiv: 2607.28802)
核心贡献：提出以“交互”为中心的 Agent 失败分类学，将故障精确定位到模型、Harness、用户、工具、记忆或环境的具体交互环节，而非笼统归结为系统级结果。
为什么值得读：这是目前最系统的 Agent 故障定位框架，直接解决“模型不行还是工程不行”的核心争论。对 Agent 产品经理和工程师有直接实操价值。
2. Tool Specifications Matter: Uncovering and Mitigating Safety Risks in AI Agents (arxiv: 2607.29254)
核心贡献：首次通过白盒表征分析证明 schema 格式的工具规范会削弱 LLM 的内部拒绝信号，并提出 SafeKeep 推理时安全解耦方案。
为什么值得读：如果做 Agent 产品化，这篇论文发现的“工具规范降低安全性”是必须理解的风险机制。SafeKeep 方案不需要重新训练，工程落地门槛低。
3. ThinkReset: Learnable Intermediate Interface Construction for Bounded-Context Long-Horizon Reasoning (arxiv: 2607.28642)
核心贡献：识别出长链推理的核心瓶颈不是压缩而是缺少可复用的“中间接口”，并指出奖励驱动的长链 RL 在上下文窗口耗尽前会鼓励“过早猜测”而非继续推理。
为什么值得读：对做 Agent 记忆和长程推理的团队有直接启示——不应只关注压缩历史，而应设计可跨回合复用的状态接口。
