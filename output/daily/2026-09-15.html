🔬 值得深挖的论文/报告
ZGCM-1: A Fully Open and Extremely Efficient Foundation Model for Math and Agentic Search（arXiv: 2609.13356）
核心贡献：第一个明确提出"小模型不能被动记忆开放网络，但可以通过刻意内部思考 + 主动外部工具调用克服参数量限制"的从零训练 7B 模型。采用门控滑动窗口与全注意力交错架构，将交互轨迹重构为 MDP 进行 Mid-Training。
为什么值得读：如果这篇论文的方法论被验证可复现，它可能重新定义"基础模型"的最低有效参数量。对于 Agent 工程团队，MDP 化的 Mid-Training 思路可以直接迁移到领域 Agent 的训练流程中，减少对 RLHF 的依赖。
Asclepius: An Adaptive Harness for Long-Horizon Clinical Agents（arXiv: 2609.13543）
核心贡献：用急诊科轮班模拟器（连续时间、资源压力）暴露当前 Agent 的"诊断正确但执行不及时"鸿沟，并将长时程失效模式操作化为可计数的三类 per-trace 指标。
为什么值得读：这是目前最接近"生产环境 Agent 可靠性测试"的学术工作。任何做多步骤 Agent 产品的团队都能从它的失效模式分类中直接找到自己的 bug。急诊场景的"时间-资源-正确性"三维压力模型是设计 Agent 评估集的好模板。
Generalized Agent Iteration: One Formal Framework for Iterative Policy Improvement and Recursive Self-Improvement（arXiv: 2609.13406）
核心贡献：提出 GAI 框架，将经典强化学习中的广义策略迭代（GPI）与递归自我改进（RSI）统一为同一种学习范式。
为什么值得读：RSI 长期停留在哲学讨论层面，这篇论文给了它一个可操作的形式化基础。对于关注 AI 安全与 Agent 自主性的研究者，这是一个思考工具：它让你能判断一个系统到底是在"迭代优化"还是在"真正自改进"。与生数科技同日发布的 RSI 相关动态形成呼应。
