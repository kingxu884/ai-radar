🔬 值得深挖的论文/报告
1. 《EntropyMoE: Entropy-Aware Sparse Expert Routing for Tokenizer-Free LLMs》
核心贡献： 提出了一种为无 Tokenizer 的字节级大模型设计的混合专家架构。该架构的核心创新在于，它根据每个动态字节块（patch）的“信息熵”进行路由，而非传统 MoE 的固定路由方式。这使得模型能将计算资源更自适应地分配给信息量大的字节块，从而避免了在细粒度建模时对所有 patch 进行同样耗时的计算。
为什么值得读： 它解决了下一代 LLM 架构的一个根本性问题：如何在不依赖固定词汇表的情况下，实现高效且灵活的计算分配。这直接关系到模型处理多语言、稀有词汇和文本噪声的能力，是通向更通用、更鲁棒的语言模型的关键一步。
2. 《AgentPatch: Coarse-to-Fine Weak-Task Repair for Merging Agentic Multimodal Large Language Models》
核心贡献： 针对当前 Agentic MLLM 各自为战（专精于特定工具或环境）的现状，提出了“Agentic MLLM 合并”的挑战，并给出了一种无需训练的修复框架 AgentPatch。该框架能够在合并多个模型时，精准地修复因能力稀释而变弱的“弱任务”，并防止对长程任务执行至关重要的行为被遗忘。
为什么值得读： 这是解决“如何构建一个通用 Agent 大脑”这一核心难题的工程化尝试。它直接回应了 Multi-Agent 和 Subagent 架构中，如何有效整合不同专长能力的痛点，是向强大且统一的 Agent 模型迈出的探索性一步。
3. 《WebRider: Persona-Conditioned Intent Controllers for Live-Web Assistance》
核心贡献： 揭示了现有网页 Agent 的致命缺陷：虽然能完成任务，但大部分情况下都会违反用户的隐性策略。论文提出了“意图合约”概念，将用户的任务委托形式化为一个包含目标、约束、证据义务和任务本地化偏好的结构化记录，并以此约束 Agent 行为。
为什么值得读： 这是一篇极佳的 Agent 产品化实践指南。它指出了当前 Agent 评测（只看最终结果）的盲区，并为构建更可靠、更符合用户期望的下一代 Agent 提供了一个清晰的技术框架，对于从事 Agent 产品设计和工程化落地的团队是必读材料。
