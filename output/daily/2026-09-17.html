2. Memory Has Geometry: Non-Uniform Geometric Memory for Long-Horizon Personalized AI
核心贡献：将长程记忆建模为用户特定的动态状态空间。不是把记忆当成静态向量搜索，而是用“几何”来描述记忆的稳定/波动区域、漂移速率和异质邻域。
为什么值得读：目前 Agent 记忆多为简单的 RAG 拼接，效果极其僵硬。这篇论文提供了一种更贴近人类记忆运转的数学框架，是构建下一代“越用越懂你”的 Agent 的底层理论基础。
3. The Other Half of the Memory Wall: Serving 35B MoEs from SSD with Trained Routing Prediction (Edge0)
核心贡献：通过训练一个“预路由器”提前猜测下一层该激活哪个专家，把 MoE 的 SSD 读取延迟隐藏在计算重叠区，使得消费级硬件也能跑满血 35B MoE。
为什么值得读：堪称极致的推理工程实践。完美解决了“模型大到装不进显存怎么办”的难题，其“提前预判”的网络架构思路对边缘计算和本地化 Agent 部署极具参考价值。
