🔬 值得深挖的论文/报告
1. Do Not Restart: Residual Completion for Stateful Agent Handoffs（arXiv 2609.13800）
核心贡献：将 Agent 交接形式化为"承诺约束的剩余完成"问题，提出 CFRC 框架——冻结已接受进度、闭包剩余契约、证据链接图、仅当剩余被覆盖时才允许执行。论文证明了合约相对部分正确性。
为什么值得花时间：直接回答"Agent 被中断后如何恢复、两个 Agent 如何交接"这类生产环境每天遇到的真实问题。如果你在做 Agent 编排或 Harness 设计，这篇的契约模型可以作为架构参考。
2. Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act（arXiv 2609.16268）
核心贡献：通过受控合成环境证明，RL 训练的工具调用策略会基于表层线索（非因果相关的提示特征）选择工具，而非真实任务需求。反事实评估显示捷径策略在分布外场景系统性失败。
为什么值得花时间：工具调用是 Harness 工程的核心，但大多数团队只关心"调对了没"，很少追问"为什么调"。这篇揭示了 RL 优化的隐性风险——你的 Agent 可能只是背了训练数据的相关性，换场景就崩。
3. Retrieval-Driven Memory Reconsolidation for Long-Term LLM Agents (REALM)（arXiv 2609.16053）
核心贡献：不同于"存储时更新、检索时只读"的传统记忆系统，REALM 让检索反馈持续驱动记忆的重组与演化，并用认知科学中"记忆再巩固"的机制解释这种自组织过程。
为什么值得花时间：长期 Agent 的记忆架构是 Harness 工程的深水区。这篇不仅提出了新框架，还指出了现有记忆系统的根本缺陷——记忆应该在使用中进化，而不是累计堆积。适合正在设计多会话 Agent 的团队。
