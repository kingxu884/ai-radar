第三部分：🔬 值得深挖的论文/报告

1. SAGE: A Statistical Acceptance Gate for Self-Evolving Agents — arXiv:2609.36043

核心贡献：将 self-evolving agent 的接受门控形式化为统计决策问题，解决当前“平均验证分数提升即保留”造成的永久回归和 Optimizer's Curse。

值得读的原因：如果正在做 Agent 的技能文档/工作流自更新，这篇直接解决了编辑接受策略中最容易被忽视的部分。它是 Harness 工程从经验规则走向统计控制的重要工作。

2. Memory Is a Derivation: The Distributed-Evidence Paradox in Long-Term Agents — arXiv:2609.36130

核心贡献：提出长期 Agent 记忆的派生合法性问题，区分证据范围、组合有效性、准入可靠性三个耦合要求，指出压缩可能引入历史未支持的关系。

值得读的原因：对上下文管理、记忆持久化和多轮推理中的“记忆污染”有理论化分析。适合正在构建长期运行 Agent 或记忆系统的工程师。

3. Beyond Symmetric Agents: Cognitive Diversity and Multi-Agent Debate in Small Language Models — arXiv:2609.35875

核心贡献：在 23 个模型、5 个任务、5500+ 次运行中系统拒绝“认知多样性是多智能体辩论增益驱动因素”的假设，发现与预算匹配的多数投票对照相比，辩论增益并不稳定。

值得读的原因：直接冲击 Multi-Agent 设计中的“多样性神话”。如果你在考虑用多 agent 提升推理，这篇能帮你避免浪费预算在无效的角色/人格多样性上。
