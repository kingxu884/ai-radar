🔬 值得深挖的论文/报告
1. Agents Trust Tools Too Much: Measuring Reliance on Unreliable Tools (arXiv:2609.05587)
核心贡献：首次系统测量 LLM Agent 在工具返回被污染时的过度信任行为，覆盖网页搜索、子 Agent 委派和代码执行三种工具，并分析推理轨迹揭示盲目采纳的原因。
值得读：它直接暴露了企业级 Agent 部署中最危险的静默故障模式，是 Harness 工程必须面对的现实问题。推荐给所有构建生产级 Agent 系统的工程师。
2. When Does Memory Help? A Cost-Aware Evaluation of Long-Term Memory in Tool-Using LLM Agents (arXiv:2609.05441)
核心贡献：提出 MERIT 基准，在三个领域的 episodic 工具使用任务中测量记忆的边际效用，包含自动泄漏检查、记忆损坏控制和完整 token/美元计量。
值得读：它把长时记忆从“是否记住”推向“是否值得记住”，提供了成本效益分析框架，是 Agent 记忆系统设计的关键参考。
3. Beyond Prompts: Measuring and Optimizing LLM Tool-Agent Harnesses (arXiv:2609.05736)
核心贡献：将固定模型下的 Harness 选择形式化为资源受限优化问题，提出 RelLift95(B) 等指标，并用 prompt-only 和 prompt-plus-middleware 两种优化器实例验证。
值得读：它为 Harness 工程提供了方法论基础，说明不重训模型、仅优化工具边界中间件也能获得稳定提升。适合从事 Agent 编排、MCP 中间件和推理优化的工程师。
