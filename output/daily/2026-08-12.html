🔬 值得深挖的论文/报告
When LLM Agents Negotiate: Private Information and Dynamic Bargaining in Supply Chains [arXiv:2608.07538]
核心贡献：在经典的供应链供求博弈中，测试了 9 款主流 LLM（含 OpenAI, Google, 阿里）的谈判能力。实验发现 Agent 能捕获 95.4% 的理论剩余价值，但延迟回合导致 21-34% 的损耗。
为什么值得读：这是极少数不是跑分而是测“经济理性”的论文。它揭示了当前 Agent 在商业自动化中的核心短板——不是不够聪明，而是沟通效率低。对于关注 Agent 产品化、金融交易算法的人来说，这是必读文献。
Persistent Semantic Entities in Tool-Augmented LLM Systems [arXiv:2608.07952]
核心贡献：形式化了跨会话的“语义幽灵”问题（PSEs）。实验证明，Agent 工具链中存在的偏好污染会在不同会话间通过命名绑定（Name Binding）无限期存活，即使模型规模扩大到 1T 参数也无法免疫。
为什么值得读：这是对 MCP 和 Agent Harness 工程的安全警示。当你在多个 Agent 之间通过 MCP 共享工具和个人数据时，恶意污染会像病毒一样潜伏。这是构建企业级 Agent 系统必须直面的供应链安全问题。
CommitKV: Lifecycle-Aware KV Cache Compression via Commit Transitions for Multi-Turn Agents [arXiv:2608.07855]
核心贡献：针对多轮 ReAct Agent 长对话导致的 KV Cache 爆炸，提出通过识别“Commit”交易点来释放不再需要的显存状态，比传统的基于注意力分数的驱逐法更精准地保留了重激活所需的信息。
为什么值得读：这是 Agent 落地的基础设施级优化。直接解决 Claude Code 或 Cursor 在长会话后变慢、显存溢出的问题。是 Harness 工程师必须掌握的上下文管理技术。
